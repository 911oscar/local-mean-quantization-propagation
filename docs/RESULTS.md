# Results and definitions

Positive gain means lower candidate error after correction. Same-input FP32 suffix: 694 positive / 26 negative / 0 unresolved. Full directional predictor: 24 true negative detections, 2 missed negatives, 5 false alarms, 689 correct positives. For actual cast residual r_tilde, define a_c=e−r_tilde, K=||J a_c||²/N, C=2〈J a_c,J r_tilde〉/N, L=K+C, R_NL=D−L and T as the sum of the two actual output errors. K>0 and −C/K>1 iff L<0 is an identity, not independent evidence. Group quantiles must be taken on per-case ratios; do not subtract separate medians.

`mechanism_all_cases.json` has 720 scalar records; `adverse_and_false_alarm_cases.json` retains all 31 adverse/false-alarm cases. `margin_groups.json` and `margin_cases.json` contain |L|/T, |R_NL|/T and |R_NL|/|L|. Zero denominators are recorded separately. `abstention_curve.json` reports the complete fixed threshold grid: threshold .2 has zero errors among 654 retained cases, but retains only 3/26 actual negatives. This conditional result is not a validated selector.

`ce_cases.json` and `ce_summary.json` separate original FP32 loss scores from stable FP64 rescoring of the same FP32 logits, not FP64 network inference. Positive/negative/unresolved rescored counts are 375/345/0 (FP32 suffix) and 369/351/0 (INT8-led). Compute CE stably as logaddexp(0, logsumexp(logit_j−logit_c, j != c)). The comparison scale is 64 eps64 × (1+|CE_n|+|CE_b|+max|logits_n|+max|logits_b|). Half-ULP32 logit envelopes test storage sensitivity, not total hardware rounding.

`task_statistics.json` includes all six modes and the bounded block-width/target-precision grid. Accuracy is a fraction; changes ×100 are percentage points. The accuracy-change interval includes zero despite more than halving logit MSE. `reference_levels.json` and `requantization.json` report actual subsequent INT8 outcomes. Amplitude challenges are controlled perturbations, not new natural samples.

`cost_summary.json` uses the corrected final timing run only, with all configurations prewarmed, repeated warnings suppressed, synchronized device execution and randomized mode order. Scope: CPU uint8 input → normalization/transfers → all computations/casts → CPU logits. Report milliseconds per batch, not per image; min/max span seven means of 20 repeats. `cold_total_seconds` is a legacy field name meaning **first configuration call within a shared process**, including target preparation, excluding model load, and not a fair cold-start ranking. `cost_components.json` consists of separately synchronized, nonadditive components. Process peaks hold all configurations, not a minimal deployment. No energy or speed advantage over FP32/AMP is claimed.
